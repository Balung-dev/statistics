# 統計學互動學習

以純靜態 HTML 製作的統計概念小工具集合，無需安裝或建置，於瀏覽器開啟即可使用。所有運算皆在本地端完成。

## 使用方式

1. 以瀏覽器開啟專案根目錄的 **`index.html`**（雙擊檔案或拖入視窗即可）。
2. 從首頁卡片進入各單元；細部頁面含統一頂欄、麵包屑與頁尾（樣式定義於 `site.css`）。
3. 若改以靜態網站伺服器提供，連結方式相同。

## 專案結構

| 檔案 | 說明 |
|------|------|
| `index.html` | 入口頁：主題簡介與四張工具卡片連結 |
| `site.css` | 全站共用：頂欄、頁尾、麵包屑等版型樣式 |
| `stdev.html` | 標準差計算互動圖解（預設資料可改為手動輸入） |
| `normal.html` | 標準常態：Z 分數與累積百分比互換、曲線與鍵盤微調 |
| `simulate.html` | 常態式整數模擬、直方圖、統計摘要與 CSV 匯出 |
| `correlation.html` | Pearson 相關、散佈圖與線性回歸、手動/自動資料與 CSV |

## 各單元摘要

- **標準差計算互動圖解**：逐步展示平均、離差、變異數與標準差；預設資料為 `30, 40, …, 90`，可透過「手動輸入資料」清空並輸入新數據後套用。
- **Z 分數與累積百分比**：標準常態分佈下左尾機率與 Z 互算，並附圖示。
- **常態分佈資料模擬**：依範圍與平均、標準差產生整數樣本，可複製或匯出單欄 CSV 供 Excel 使用。
- **相關性與線性回歸**：散佈圖、Pearson *r*、最小平方回歸直線，支援模擬資料或手動點選。

## 技術備註

- **Tailwind CSS**、**Chart.js**、**Noto Sans TC** 以 CDN 載入。
- 無後端、無套件建置流程；離線前需至少載入過 CDN 資源（或自行改為本機檔案）。
